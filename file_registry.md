# Project Pandem - File Registry

This registry keeps track of the skills and data files that exist locally but are not tracked in the public Git repository (as they reside in `.gitignore`'d directories).

## SKILL/ (Verification Skills)
* `github_skill.md`: GitHub MCP Verification Skill for verifying PR status, coverage, and reviews.
* `venice_ai_skill.md`: Venice.ai Ratio Scoring Verification Skill for multi-party dynamic revenue splitting based on commits/social metrics.
* `vlayer_zktls_skill.md`: vlayer Session Proof Verification Skill for web2 verification using zkTLS (GitHub, Polymarket, Social Media).

## DATA/ (Project Data and Mock Outputs)
* `Pandem.md`: The comprehensive writeup, vision, architecture, and documentation for Project Pandem v3 (ERC-8183 Commerce Layer).
* `mock_github_data.json`: Example payload representing a merged pull request and coverage run.
* `mock_social_data.json`: Example payload for a social agent's performance metrics and a generated Venice.ai ratio score.
